## Before the conference

1. Get your session slot and running order from the program chairs. Talk length: `TALK_LENGTH_TBD`.
2. Confirm each speaker's name, affiliation, talk title and order. Write a one-line introduction for each.
3. Tell speakers the AV setup and when to send slides: `SLIDE_DEADLINE_TBD`.
4. Register ({{ c.links.payment }}) with the role "Session chair" or "Session organizer". Use the same email as in CMT.

## On the day

1. Arrive 15 minutes before your session. Check in at the registration desk first and wear your badge.
2. Test the projector, wireless microphone and laptop audio connection with the AV technician. Test the first speaker's slides.
3. Start on time. Introduce yourself, the session and each speaker.
4. Keep time. Signal at `WARNING_MINUTES_TBD` minutes left. End each talk on schedule, even if questions remain.
5. Run questions: repeat each question into the microphone, then ask the speaker to answer.
6. If a speaker is absent, move the next talk only if the program says so. Otherwise take a short break. Do not run early.
7. Close the session, point people to the next break, and thank the speakers.

## After the session

Send the program chairs any notes on problems (AV, timing, no-shows) the same day.
